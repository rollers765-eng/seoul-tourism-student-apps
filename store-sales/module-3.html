실무 7

매장 판매 마무리

“살게요!”라고 말한 순간, 판매는 끝난 걸까?

학습 목표
  • 고객의 추가 요구를 충족하며 결제·포장·배송 의뢰·환송까지 수행할 수 있다.
  • 구매 결정 이후에도 남은 업무가 고객 경험을 완성한다는 것을 설명할 수 있다.
  • 1상품 선택
  • 2구매 결정
  • 3결제
  • 4포장
  • 5배송 의뢰
  • 6고객 환송
  • 7판매 완료

매장 판매 마무리란 고객의 구매가 결정된 이후 결제, 포장, 배송 의뢰, 고객 환송 등의 업무를 수행해 고객의 구매 경험을 완성하는 과정입니다.

장면 · 계산은 정확했는데 직원 “18,500원이요.” → 손님 “카드요.” → 직원 “여기요.” → 손님 “적립은요?” → 직원 “결제 전에 말씀하셨어야 하는데요.” → 손님 “아… 됐어요.”

계산은 맞았습니다. 그런데 서비스도 좋았을까요? 결제 금액이 맞는 일과 손님이 기분 좋게 나가는 일은 다른 문제입니다.

손님이 가장 불쾌해하는 네 장면 ① 결제 금액을 잘못 계산했다 ② 케이크 포장이 망가졌다 ③ 배송지가 잘못 입력되었다 ④ 결제 후 아무 말 없이 다음 손님을 응대했다. 네 가지 모두 구매 결정 이후에 일어납니다.
실무 8

결제하기

결제는 돈을 받는 일이 아니라 요구를 확인하고 결과까지 안내하는 일

결제 업무는 돈이나 카드를 받아 계산하는 것만이 아니라, 정확성(금액·수량) · 고객 요구 확인(포인트·쿠폰·영수증) · 설명(고객이 이해하는 안내) · 태도(마지막 인상)를 함께 수행하는 서비스 과정입니다.

결제 업무의 네 단계
단계확인할 것직원 멘트 예
1. 고객 정보회원·포인트·영수증 필요 여부“적립이나 쿠폰 사용 도와드릴까요?”
2. 결제 방법현금·카드·모바일·상품권“18,500원입니다. 카드로 결제 도와드릴까요?”
3. 결제 수행수량 → 금액 → 결제 → 승인“결제 진행하겠습니다.”
4. 결과 안내영수증·적립·혜택 확인“결제 완료되었습니다. 포인트 185점 적립됐고, 영수증 여기 있습니다.”
결제수단별로 먼저 확인하는 것
수단확인 포인트자주 나는 실수
현금금액 확인, 거스름돈거스름돈 계산 오류
카드승인 여부, 소유자 확인, 서명승인 전 상품 전달
모바일 페이결제 완료 화면, 승인 금액화면만 보고 완료로 착각
상품권·쿠폰사용 가능 여부, 기한, 잔액기한 확인 없이 거절하거나 그냥 사용
포인트적립·사용 순서결제 후에 사용 요청을 받음
알아 둘 개념과 법규 POS(Point of Sale)는 매장의 결제·정산 시스템, 시재는 영업 전후 현금 잔액입니다. 고객 정보는 필요한 범위에서 동의를 받아 다루며(개인정보 보호법), 전자금융거래와 영수증 발급에도 정해진 기준이 있습니다. 판매 금지 연령·신분증 확인 기준은 매장에 게시된 기준을 따릅니다.
판단해 볼 문제 손님이 “친구 카드인데 대신 결제해 주세요”라고 한다 · 카드 수수료 때문에 결제 금액보다 더 받는다 · 영수증이 필요 없다고 해서 발급하지 않는다 · 이벤트 응모 명단의 전화번호를 다른 손님에게 알려 준다. 네 가지 모두 해서는 안 되는 일에 해당합니다. 이유를 한 줄씩 말해 보세요.

문제

같은 말, 다른 서비스 A: “적립되나요?” → “네.” → “어떻게 해요?” → “전화번호요.”
B: “적립되나요?” → “네. 휴대전화 번호로 적립하실 수 있습니다. 번호 입력 부탁드립니다.”
틀린 말은 둘 다 하지 않았습니다. 차이는 고객이 이해하는가입니다.

먼저 해야 할 일부터 누르세요. 틀리면 알려 드립니다.

실무 10

배송 의뢰하기

배송은 매장 문 밖에서도 계속되는 판매 서비스

NCS 핵심 · 배송 의뢰에서 직원이 하는 다섯 가지
  • 배송 희망 여부 확인 — “배송해 드릴까요?”
  • 고객 요구에 맞는 배송 방법 선택
  • 배송 주문서 작성
  • 배송 담당자에게 주문서 전달
  • 판매 상품 수령 여부 확인
고객이 “배송해 주세요”라고 하면 — 먼저 확인하는 네 가지
질문확인할 내용자주 나는 실수
무엇을?상품명·수량수량을 구두로만 확인
어디로?수취인·연락처·주소(동·호수까지)주문자와 수취인을 바꿔 적음, 번호 한 자리 오류
언제까지?희망 도착일·시간대“빨리”라고만 적음
어떻게?상품 특성·주의사항·배송 방법파손·냉장 주의사항 누락
배송 의뢰하기 vs 상품 배송하기 배송 의뢰는 매장 직원의 고객 접점 업무입니다(희망 확인 → 방법 선택 → 주문서 작성 → 담당자 전달 → 수령 확인). 상품 배송은 실제 배송 수행·관리 업무입니다(주문 확인 → 업체 결정 → 운송장 작성 → 배송 실행 → 완료 확인). 오늘 수행평가의 중심은 왼쪽입니다.
배송 문제 네 가지 · 원인과 대응
문제주요 원인예방대처
미배송전표 누락, 주소 불명확, 포장 불량상품별 전표 부착, 주소 확인재배송 또는 금액 배상
오배송주소 입력 실수, 전표 부착 오류주문서와 실제 상품 대조재배송, 환불·차감
지연 배송물량 급증, 배송 회차 누락약속 시간 신중히, 사전 안내우선 배송, 고객에게 먼저 설명
파손·변질고온, 압력, 포장 불량냉장·냉동 준수, 적재 주의매장 과실이면 재배송 또는 환불

대응의 순서는 늘 같습니다. 사실 확인 → 고객 응대(사과·요구 확인) → 해결 안내 → 후속 조치. 원인을 확인하기 전에 택배기사 탓부터 하지 않습니다.

배송 확인과 개인정보 수령 여부를 확인하려면 개인정보 동의가 필요합니다. 동의가 있으면 고객 이름으로, 없으면 보낸 사람 이름으로만 문의합니다. 확인할 것은 본인 여부, 수량, 외관·내용물 이상, 직접·대리 수령, 배송 기사 응대, 불편 사항입니다.

받는 사람, 연락처, 주소, 받는 날을 확인해 주세요.

입력한 내용은 이 화면에서만 쓰이고 어디에도 저장되지 않습니다. 실제 배송 정보는 개인정보이므로 수업에서는 예시 값으로 연습하세요.
