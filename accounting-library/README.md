# 서울관광고등학교 회계원리 자료집

기존 웹앱과 독립된 정적 자료집입니다. 이 폴더 안의 파일만 배포하며 기존 앱은 수정하지 않습니다.

공개 주소: https://rollers765-eng.github.io/seoul-tourism-student-apps/accounting-library/

## 자료실 이용

단원 → 계정과목 → 차시 버튼 순으로 선택합니다. 첫 단원과 계정과목은 자동 선택되어 첫 화면에서도 자료를 바로 열 수 있습니다. 목록은 수업자료명 / 수업슬라이드 / 활동지 열기 / 활동지 다운로드 / 관련 키워드 순서입니다. 휴대폰에서도 같은 순서로 표시합니다.

교표·교명과 캐릭터는 사용자가 제공한 원본 PNG를 그대로 사용합니다.

## 수업 추가하기

1. `materials/` 안에 새 영문 폴더를 만듭니다. 예: `cash-02`.
2. 공개 가능한 학생용 슬라이드 HTML, 활동지 HTML 또는 PDF를 넣습니다.
3. `materials.json` 배열에 아래 형식의 항목을 하나 추가합니다. 파일만 복사하면 자동 노출되는 방식이 아니라, 이 목록에 등록한 자료만 공개 화면에 표시됩니다.
4. GitHub에 커밋한 뒤 Pages 반영을 기다립니다. 앱 설치나 별도 빌드는 없습니다.

```json
{
  "id": "cash-02",
  "chapter": "Ⅱ. 자산의 회계 처리",
  "chapterOrder": 2,
  "unit": "유동자산",
  "unitOrder": 1,
  "accountOrder": 1,
  "account": "현금",
  "lesson": 2,
  "title": "현금 거래의 회계처리",
  "description": "현금의 증가와 감소를 분개해 봅니다.",
  "pages": "교과서 쪽수",
  "tags": ["현금", "분개"],
  "slides": "materials/cash-02/slides.html",
  "worksheetHtml": "materials/cash-02/worksheet.html",
  "worksheetPdf": "materials/cash-02/worksheet.pdf"
}
```

`chapter`에는 교과서 대단원을 기록합니다. `chapterOrder`, `unitOrder`, `accountOrder`는 교과서에 따른 표시 순서입니다. 같은 단원·계정과목의 자료는 같은 순서 값을 사용합니다. 등록한 단원만 버튼으로 표시되며, 자료 없는 단원을 임의로 만들어 표시하지 않습니다.

없는 파일 항목은 `null`로 지정합니다. 파일명은 영문·숫자·하이픈·밑줄을 사용하고, 경로는 `materials/`로 시작합니다. `lesson`은 숫자, `id`는 자료마다 고유한 값을 사용합니다. PDF만 있는 활동지도 지원합니다. 파일 경로 대소문자와 JSON 쉼표를 확인하세요.

## 공개 전 점검

- 이 저장소와 Pages는 공개입니다. 목록에서 빼더라도 저장소에 올라간 파일은 공개됩니다.
- 교사용 원본, 정답 PDF, 학생 실명·학번·연락처, API 키는 이 폴더뿐 아니라 공개 저장소 어느 위치에도 올리지 않습니다.
- CSS 숨김, 투명 처리, 비밀번호를 적은 JavaScript는 보안이 아닙니다. 문제 정답은 HTML과 스크립트에서 실제 삭제해야 합니다.
- 최초 자료의 활동지 정답·교사 모드·개별 정답 토글을 제거했습니다. O/X 선택지는 둘 다 표시해 정답 위치가 드러나지 않도록 했습니다.
- 슬라이드의 숨겨진 분개 정답·발문 답·퀴즈 채점은 제거했습니다. 퀴즈는 선택 기록만 표시합니다. 일반적인 개념 설명과 그래프의 학습 예시는 유지합니다.
- 첨부 원본은 공개하지 않았습니다. 교사용 원본은 사용자가 가진 원본 파일을 이용하세요.

## 유지하는 기능과 의존성

자료집 본체는 외부 라이브러리·서버·데이터베이스·분석 도구를 사용하지 않습니다. 원본 HTML 자료에는 Tailwind CDN, Pretendard, Font Awesome이 있으며 활동지 JPG 저장에는 html2canvas가 필요합니다. 원본 기능 보존을 위해 기존 CDN을 유지했고 새 의존성은 추가하지 않았습니다. 인터넷 연결 또는 CDN 장애에 따라 HTML의 서식·JPG 저장이 제한될 수 있습니다. PDF는 별도로 내려받아 사용할 수 있습니다.

슬라이드 이동·목차·효과음·전체화면·그래프, 활동지 인쇄·JPG 저장을 유지합니다. 작은 화면의 슬라이드는 세로로 스크롤할 수 있으며 활동지는 A4 비율을 유지하여 가로로 스크롤합니다. 자료집 자체는 휴대폰 폭에 맞게 표시됩니다.

현재 PDF는 학생용 HTML에서 생성한 A4 인쇄본입니다. 활동지 내용을 바꾸면 PDF도 다시 생성해야 합니다. HTML의 인쇄 버튼에서 PDF로 저장할 수 있습니다.
