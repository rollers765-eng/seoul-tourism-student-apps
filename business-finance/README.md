# 경영·금융 교과교실

웹앱 모음(`/`) → 경영·금융 교과교실(`/business-finance/`) → 과목별 자료실.

현재 회계원리 자료실은 기존 `/accounting-library/` 주소로 연결합니다. 회계 개념 연습장과 면접 앱의 주소는 유지합니다.

확장 예정 순서: 성공적인직업생활 자료실, 매장판매 자료실, 회계정보처리시스템 자료실.
자료 없는 과목은 준비 중으로 표시하며 빈 링크를 만들지 않습니다. 과목 자료실을 추가할 때 해당 과목 카드의 준비 중 표시를 제거하고 실제 자료실 링크를 추가합니다. 학교 이미지와 공통 스타일은 기존 회계원리 자료실의 파일을 재사용합니다.
