시험 구조와 KcLep의 흐름

이 단원의 목표전산회계 2급의 배점 구조와 실무 범위를 알고, 프로그램 메뉴 순서를 설명할 수 있다.

핵심 개념

한 번의 시험, 60분

  • 이론 30%(회계원리 4지선다) + 실무 70%
  • 두 영역을 합산해 100점 만점에 70점 이상이면 합격
  • 이론·실무 별도 과락은 없음
2026년 공개 안내 기준 · 세부 문항 수와 배점은 시행처 공고 확인

실무 배점의 무게중심

  • 거래자료 입력(일반전표) 40%
  • 기초정보 등록·수정 20%
  • 입력자료·제장부 조회 10%
  • 구분별 비중은 ±10% 범위에서 조정될 수 있음

2급의 범위

  • 상기업의 일반전표와 결산정리가 중심
  • 매입매출전표·원가회계·제조업 결산은 2급 범위가 아님
  • 결산정리사항도 일반전표 입력 메뉴에서 처리

프로그램의 흐름

  • 기초정보관리 → 일반전표 입력 → 장부 조회 → 결산정리
  • 순서를 건너뛰면 뒤에서 반드시 되돌아온다

시험장 기본

  • 시험지의 종목·급수·문제유형(A/B)을 프로그램에 먼저 입력
  • 이론 답안은 [이론문제 답안작성] 메뉴에서 입력
  • 마지막에 [답안저장(USB로 저장)] 후 전송 완료 확인

현장에서는

문제유형 A/B를 잘못 고르면 시험 종료 뒤에는 바꿀 수 없고 다른 유형으로 채점됩니다. 시작 전에 종목·급수·문제유형·페이지 수를 확인하는 데 30초를 쓰세요.

이 단원의 목표회사·거래처·계정과목·전기 잔액을 정확히 등록하고 검증할 수 있다.

핵심 개념

회사등록

  • 사업자등록증에 따른 회사명·사업자번호·대표자·업종
  • 회계기간(회계연도) 설정

  • 거래처 코드·명칭·사업자번호
  • 매입처와 매출처 구분
  • 코드 중복은 전표에서 거래처 혼동을 만든다

계정과목과 적요

  • 기본 계정과목 확인, 필요한 계정 추가
  • 계정 코드 오선택이 가장 잦은 실수
  • 적요는 거래 내용을 남기는 짧은 설명

전기분재무제표

  • 전기 재무상태표의 자산·부채·자본을 입력
  • 차변 합계와 대변 합계가 맞아야 함
  • 누락하면 이후 모든 잔액이 틀어짐

  • 전기분 거래처별 채권·채무 잔액 등록

결산정리

이 단원의 목표발생·이연의 원리로 결산정리분개를 세우고, 상기업 결산을 마칠 수 있다.

핵심 개념

결산정리의 원리: 발생과 이연

  • 현금이 오간 때와 수익·비용이 발생한 때는 다를 수 있다
  • 발생: 아직 지급·수령하지 않았지만 이미 생긴 비용·수익
  • 이연: 이미 지급·수령했지만 다음 기간에 속하는 비용·수익

상기업 결산의 기본

  • 기말상품재고를 반영해 매출원가를 조정
  • 소모품의 미사용분은 자산으로 남김
  • 감가상각비·대손상각비 계상
매출원가 = 기초상품 + 당기매입 − 기말상품

대표 결산정리분개

  • 감가상각: (차)감가상각비 / (대)감가상각누계액
  • 미지급비용: (차)비용 / (대)미지급금
  • 선급비용: (차)선급비용 / (대)비용
  • 미수수익 / 선수수익도 같은 원리

입력 위치

  • 2급은 결산정리사항도 일반전표 입력 메뉴에서 처리
  • 결산일자를 기준으로 입력
  • 상기업에 한정

결산 후 확인

  • 수정 후 시산표의 차대 일치
  • 자산 = 부채 + 자본
  • 당기순이익과 자본 변동이 일치

현장에서는

소모품 100,000원을 처음에 전부 비용으로 기록했고, 결산일에 30,000원이 남아 있습니다. (차)소모품 30,000 / (대)소모품비 30,000으로 남은 부분을 자산으로 되돌립니다. 처음부터 소모품(자산)으로 기록했다면 사용한 70,000원을 비용으로 옮기는 분개가 필요합니다.

이 단원의 목표입력한 전표를 정확히 고치고, 수동·자동 결산을 구분해 마칠 수 있다.

핵심 개념

전표 수정

  • 거래처·계정과목·일자·금액을 바꾼다
  • 삭제 후 새로 입력하는 방법도 있다
  • 수정 전 대상 전표의 일자·번호를 확인

수동결산

  • 손익의 예상: 미지급비용·미수수익
  • 손익의 이연: 선급비용·선수수익
  • 기타 결산정리사항을 직접 분개

자동결산

  • 결산자료입력 메뉴에서 처리
  • 상품매출원가(재고자산명세서)
  • 감가상각비·대손상각비

결산 후 확인

  • 재무상태표 자산 = 부채 + 자본
  • 손익계산서 당기순이익
  • 합계잔액시산표 차대 일치

실수 포인트

  • 자동결산 자료를 수동분개로 한 번 더 넣어 이중 계상

  • 선급·미지급 방향 혼동
