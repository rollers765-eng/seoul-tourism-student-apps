# 서울관광고 온라인 면접장 · 시범판

## 이용 안내
- 3D 화면이 열리지 않는 기기에서도 교실 찾기와 좌석 이동 버튼으로 면접 질문과 타이머를 이용할 수 있습니다.
- 질문은 1번 필수와 나머지 중 네 개이며, 1번은 기본 60초, 나머지는 기본 90초입니다. 음성 인식을 사용하지 않고도 타이머를 실행할 수 있습니다.
- 음성 인식은 기기와 브라우저에 따라 사용할 수 없거나 사용자의 음성이 브라우저 서비스에 전송될 수 있습니다. 답변 글과 면접 진행상황은 다른 방문자에게 전송하지 않습니다.
- 실시간 접속에는 무작위 접속 식별자와 가상 공간 위치만 전송합니다. 응원은 미리 정한 세 가지 문구만 공유합니다.
- 감사나무의 별칭과 메모는 모두에게 공개되므로 이름, 연락처, 구체적인 개인정보를 입력하지 않도록 안내해 주세요.

## 감사나무 관리
프로젝트 소유자는 Supabase 대시보드의 Table Editor에서 `gratitude_notes` 표를 열어 부적절한 메모를 확인하고 삭제할 수 있습니다. 일반 방문자에게 삭제 권한은 없습니다. 임시 점검 메모가 남아 있다면 학교 운영 전에 확인해 주세요. 공개 게시판은 수시 관리가 필요합니다.

## 운영상 한계
Supabase 무료 요금제의 사용량과 휴면 정책에 따라 공유 기능이 일시 중단될 수 있습니다. 연결되지 않아도 개인 면접과 타이머는 계속 이용할 수 있습니다. 사이트의 3D 요소는 WebGL 지원과 인터넷 연결이 필요합니다. iOS와 Android의 음성 인식·화면은 실제 기기에서 확인해야 합니다.
