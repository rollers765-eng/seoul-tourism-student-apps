# 면접장 베타 개선 계획

목표: 학교별 면접과 감사카페를 둘러보고 안내를 따라 연습할 수 있는 베타 버전.

1. 공간 좌표, 충돌 및 좌석을 함께 조정하고 로비·학과·카페 장면을 구성한다.
2. 대화 대상과 면접 전 인사 절차를 명시적인 상태로 관리하고 움직임 중단 확인을 제공한다.
3. 기존 감사나무 저장을 유지하며 편지 작성과 한 장씩 읽기를 제공하고 트리에 편지 표식을 표시한다.
4. 캐릭터 유휴 동작과 한국어 안내 음성, 배경음을 연결한다.
5. 자동 테스트와 크롬에서 주요 경로를 확인한 후 GitHub Pages에 게시한다.
